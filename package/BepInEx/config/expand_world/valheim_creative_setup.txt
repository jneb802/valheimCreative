# Setup notes
#
# 1. Install valheimCreative.dll on the dedicated server.
# 2. Copy this expand_world folder into BepInEx/config/expand_world.
# 3. valheimCreative allocates each owner a persistent creative zone and spawns
#    the creative StartTemple clone when that zone is first used.
#
#    valheimCreative.cfg uses x,y,z. The default CreativePosition is:
#
#      0,45,-13000
#
# 4. A player lies in bed and uses:
#
#      !creative
#
# 5. The owner can show an invite code with:
#
#      !creative invite
#
#    Another player joins that active zone with:
#
#      !creative join CODE
#
# 6. The player exits by using:
#
#      !return
